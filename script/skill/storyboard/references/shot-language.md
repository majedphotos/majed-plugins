## الإحداثيات

كل مكان **نسبة مئوية من الكادر**: `x` من يسار الكادر (0) ليمينه (100)، و`y` من فوق (0) لتحت (100). `w` عرض العنصر كنسبة من عرض الكادر، و`h` (اختياري) ارتفاعه كنسبة من ارتفاع الكادر. `x` و`y` دايماً **مركز** العنصر.

يسار ويمين = يسار ويمين الكادر مثل ما يشوفه المشاهد (مو يمين الشخص).

تقدر تكتب كلمة بدل الرقم: `x`: `left` (24) · `center` (50) · `right` (76)، و`y`: `top` (13) · `upper` (28) · `middle` (50) · `lower` (72) · `bottom` (88).

## رأس الملف

```json
{
  "brand": {"name": "@account", "bg": "#F4EFE7", "accent": "#7A4A21", "font": "Almarai"},
  "character": {"beard": true, "hair": "short", "headwear": "none", "glasses": false},
  "title": "عنوان اللوحة",
  "ratio": "9:16",
  "source_script": "السكربت كله حرفياً مثل ما أرسله المستخدم",
  "script": [{"part": "الهوك", "shot": 1, "text": "…"}],
  "shots": [ … ],
  "before": ["…", "…"]
}
```

| الحقل | شرحه |
|---|---|
| `brand.bg` `brand.accent` | **إجباريين** — لون خلفية الصفحة ولون التمييز من هوية المستخدم. كل ألوان الصفحة والرسم تنحسب منهم (خلفية غامقة ← الرسم يصير طباشير على لوح). |
| `brand.accent2` | اختياري — لون ثاني بهويته، يصير لون «اللي ينركّب بالمونتاج». لو ما انعطى ينحسب لون مقابل للتمييز. |
| `brand.font` | اسم خط من Google Fonts (Tajawal، Cairo، Almarai، IBM Plex Sans Arabic…). اختياري. |
| `brand.name` | اسم الحساب، يطلع فوق وتحت. |
| `character` | شكل اللي يطلع بالكاميرا بكل اللقطات: `beard` (true/false) · `hair`: `short` `long` `none` · `headwear`: `none` `ghutra` `shemagh` `hijab` `cap` · `glasses` · `outfit`: `tshirt` `shirt` `thobe` `dress` (لبس طويل فاتح) `abaya` (طويل غامق) · `dark_outfit`. الغترة تلبّسه ثوب والحجاب يلبّسها `dress` تلقائياً لو ما حددت. |
| `ratio` | `9:16` (الافتراضي) · `16:9` · `1:1` · `4:5` · `3:4`. |
| `source_script` | نص المستخدم الأصلي حرفياً. السكربت يقارنه بالتقسيم وينبّه لو كلمة نقصت أو انزادت. |
| `script` | أجزاء السكربت بالترتيب: `part` اسم الجزء، `text` نصه حرفياً (سطر جديد = `\n`)، `shot` رقم لقطته. جملة نصها بلقطة ونصها بلقطة ثانية؟ اقسمها جزئين، كل جزء بلقطته. |
| `before` | نقاط «قبل لا تصوّر». |
| `kicker` `duration` `pace` `lang` | اختيارية: سطر فوق العنوان · نص المدة بدل المحسوب · سرعة الكلام (كلمة بالثانية، الافتراضي 2.2) · `en` لصفحة إنقليزية. |
| `labels` | يغيّر عناوين الصفحة. المفاتيح: `board` `script` `for_shoot` `script_hint` `shot` `say` `direction` `before` `about` `seconds` `sec` `key_pen` `key_ov` `key_note` `no_speech`. **لو اللي تصوّر بنت** غيّر المذكّر: `{"say": "تقولين", "before": "قبل لا تصوّرين"}` واكتب التوجيه بصيغتها. |

المدة ووقت كل لقطة ينحسبون من عدد الكلمات، فلا تكتبهم إلا لو المستخدم عطاك وقت محدد. طالع شريحة الوقت بعد التشغيل: لقطة طلعت ثانية وحدة غالباً تقسيمها غلط، ولقطة المنتج أو التطبيق تبي 3 ثواني وفوق.

## اللقطة

```json
{
  "title": "المنتج: الكيس جنب وجهك",
  "direction": ["واقف بالنص، ترفع الكيس جنب وجهك.", "الاسم مواجه الكاميرا."],
  "callout": "اختياري: مربع منقّط تحت التوجيه لشي مهم",
  "say": "اختياري: ملخص بدل نص الأجزاء",
  "seconds": 3,
  "frame": { "person": {…}, "props": […], "overlay": […], "notes": […] }
}
```

- `title`: اسم الجزء ثم وصف التكوين بثلاث كلمات («الهوك: مع اللابتوب»).
- `seconds`: بس للقطة بلا كلام (لقطة منتج صامتة).
- `time`: نص الوقت يدوي («0-3 ث») لو تبي تتجاوز المحسوب.
- ترتيب الرسم: عناصر الخلفية ← كتابة `behind` ← الناس ← الطاولة والعناصر اللي قدام ← المونتاج ← الملاحظات.

## الشخص

`"person": {…}` لشخص واحد أو `"people": [{…}, {…}]` لأكثر. لقطة منتج قريبة = بلا `person` أصلاً.

| الحقل | القيم |
|---|---|
| `x` `y` | مركز **الراس**. الافتراضي بالنص، و`y` حسب الحجم. نزّله (`y` 52 إلى 60) لو فيه كتابة فوق. |
| `size` | `wide` جسم كامل · `medium` لين الخصر أو الركبة · `mclose` الصدر وفوق · `close` الوجه والكتف · `xclose` وجه مالي الكادر. أو رقم n = عرض الراس كنسبة من أقصر ضلع (medium ≈ 17)؛ وقتها الوجه يغطي x±(n÷2) و y±(n×0.35) بالكادر الطولي. |
| `pose` | `stand` (الافتراضي) · `sit` (بلقطة واسعة يرسم الرجلين مثنية؛ حط `sofa` أو `chair` وراه). القاعد ورا طاولة: بس حط عنصر `table` وهو ينقص عندها. |
| `turn` | `left` · `right` · `camera`: وين يطالع. |
| `arms` | للإيدين الثنتين: `rest` مضمومة قدامه (الافتراضي) · `down` على الجنب · `open` مرفوعة يشرح · `cross` مكتّف · `desk` على الطاولة · `hide`. |
| `left` `right` | إيد وحدة بس (يسار/يمين الكادر): نفس القيم + `wave` يلوّح · `point-camera` يأشّر على الكاميرا. |
| `point` | يأشّر على مكان: `[x, y]` أو `{"to": [x, y], "arm": "left"}`. |
| `hold` | ماسك غرض: `{"at": …, "item": {عنصر}}`. `at`: `side-left` / `side-right` مرفوع جنب الوجه · `chest` بإيدينه قدام صدره · `forward-left` / `forward-right` **مدّه قدام الكاميرا فيبين كبير** (لقطة عرض المنتج). `item` أي عنصر من الجدول تحت؛ `w` داخله يكبّره أو يصغّره، و`ratio` (الارتفاع ÷ العرض) يغيّر شكله. |
| `behind_table` | `false` لو فيه طاولة بالكادر وهو مو وراها. |
| `character` | يغيّر الشكل لهالشخص بس (ضيف، زبون). |

## العناصر

`"props": [{"type": …, "x": …, "y": …, "w": …}, …]` — اللي ينصوّر فعلاً، ينرسم بالرصاص.

حقول مشتركة: `label` كتابة على العنصر (اسم البراند بحروفه) · `rot` ميلان بالدرجات · `layer`: `back` ورا الشخص أو `front` قدامه (الافتراضي حسب النوع) · `hand`: `bottom` / `left` / `right` يد ماسكته داخلة من طرف الكادر (**للقطة القريبة بلا وجه**).

| النوع | شنو يرسم | حقول خاصة |
|---|---|---|
| `table` | حافة طاولة بعرض الكادر، وتغطي اللي تحتها | `y` مكان الحافة · `x0` `x1` لو مو كاملة |
| `laptop` | `view: back` ظهر الشاشة للكاميرا (الافتراضي) أو `screen` الشاشة مواجهة | `logo: "apple"` أو نص · `content` |
| `monitor` `tv` | شاشة على ستاند أو معلقة | `content` · `label` · `tilt` من -1 إلى 1 ميلان منظور |
| `phone` `tablet` | جوال أو تابلت | `content` · `view: back` ظهره · `label` |
| `box` `bottle` `perfume` `cup` `can` `jar` `tube` `bag` `card` `watch` `book` `plate` `burger` `shoe` `headphones` `camera` `mic` `keyboard` | منتجات وأغراض | `label` · للكوب `steam: true` · للكاميرا `tripod: true` |
| `shape` | **أي شي ثاني**: مربع بحواف دائرية واسمه عليه. جهاز بشاشة صغيرة (باور بانك، سماعة، قلاية) = `shape` مع `screen` | `label` · `shape`: `round` `rect` `circle` · `h` أو `ratio` (الارتفاع ÷ العرض) · `screen: "87%"` شاشة صغيرة ومكتوب فيها (تشتغل مع `box` بعد) |
| `car` | سيارة من الجنب، أو `view: front` من قدام | `label` · `flip: true` تعكس الاتجاه |
| `car-interior` | داخل السيارة: الشبابيك ثابتة بالكادر، والمسند والكرسي يتبعون مكان الشخص، والمقود والحزام ينرسمون قدامه (فخل إيدينه `hide`) | `wheel`: جهة المقود بالكادر، `right` (الافتراضي: سايق سيارة خليجية والكاميرا قدامه) أو `left` |
| `storefront` | واجهة محل بلوحة وباب. اللوحة واسم المحل بأعلى الواجهة (الخمس الفوقي منها)، فخل عناوين المونتاج فوق الواجهة أو نزّل الواجهة | `label` اسم المحل |
| `sofa` `chair` `shelf` `plant` `window` `picture` `door` `whiteboard` `lights` `softbox` `ringlight` | أثاث وخلفية وإضاءة | `label` للسبورة والصورة |
| `backdrop` | خلفية كاملة مهشّرة (قرين سكرين، ستارة) | `label` ينكتب فوق بالنص عند `y` 6، فلا تحط عنوان بنفس المكان · `to` وين تخلص من تحت (الافتراضي 86) |

`content` لأي شاشة: `page` صفحة أو مقال · `chart` رسم بياني · `video` · `chat` محادثة · `grid` معرض صور · `app` تطبيق بقائمة · `shop` صفحة منتج · `code` · `photo`. ومع `label` ينكتب اسم اللي عالشاشة بنصها.

نوع مو موجود بالجدول ينرسم مربع باسمه ويطلع تنبيه. الأحسن تكتبه `shape` من البداية.

## المونتاج

`"overlay": [ … ]` — اللي **ما ينصوّر** وينركّب بعدين. ينرسم ملوّن ومنقّط عشان يتميّز عن الرصاص.

حقول مشتركة: `color`: `1` (الافتراضي) أو `2` لون ثاني، أو لون شعار معيّن `"#E07B4F"` · `behind: true` ينرسم ورا الشخص (كلام ورا الراس).

| النوع | شنو يرسم | الحقول |
|---|---|---|
| (كتابة) | `{"text": "…", "x": …, "y": …}` | `size`: `huge` كلمة بعرض الكادر · `big` · `mid` · `small` أو رقم · `style`: `pill` كبسولة، `blocks` حروف مفرّغة ضخمة · `w` أقصى عرض. الكتابة الأطول من مكانها تتصغّر تلقائياً لين تدخل، فكلمة طويلة بـ`huge` تطلع أصغر مو مقصوصة |
| `list` | كبسولات تحت بعض (مزايا تطلع وحدة وحدة) | `items: ["…", "…"]` |
| `badge` | نجمة أو دائرة فيها سعر أو خصم | `text` · `w` · `shape: "circle"` |
| `caption` | مكان الكابشن | `text` اختياري · `w` |
| `logo` | مربع شعار | `text` · `w` |
| `panel` | إطار لشي ينحط بالمونتاج: تسجيل شاشة، صورة، مقطع | `label` · `content` · `w` `h` |
| `burst` | أشعة ورا الراس أو المنتج (شعار أو لمعة تطلع من وراه) | `r` نص القطر · `rays` · `text` اسم صغير فوقها («شعار البراند») |
| `floor` | أرضية شبكية (عالم ينبني ورا الشخص) | `y` خط الأفق |
| `arrow` | سهم منقّط لحركة تنسوّى بالمونتاج | `from` `to` · `text` · `at` مكان النص |
| `zoom` | إطار يبيّن وين يقرّب المونتاج | `x` `y` `w` `h` · `text` ينكتب فوق الإطار، أو بمكان تختاره `at: [x, y]` |
| أي نوع من العناصر | منتج أو جوال ينركّب بالمونتاج مو مصوّر | نفس حقول العنصر |

## الملاحظات

`"notes": [ … ]` — كلام للي يصوّر، بلون التمييز. **ثنتين بالكثير.**

| الشكل | مثال |
|---|---|
| نص وسهم | `{"text": "تفتح العلبة مع كلمة «شوف»", "x": 50, "y": 91, "to": [50, 80]}` — `to` وين يأشّر السهم (اختياري) |
| مربع منقّط | نفسه مع `"box": true` — لملاحظة تخص اللقطة كلها |
| حركة | `{"type": "arrow", "from": [76, 51], "to": [88, 62], "text": "…"}` — حركة إيد أو غرض أو كاميرا وقت التصوير |
| تقريب الكاميرا | `{"type": "zoom", "x": 50, "y": 40, "w": 50, "h": 30, "text": "الكاميرا تقرّب هني"}` — و`at: [x, y]` لو تبي النص بمكان ثاني |

النص يتصغّر وينقسم سطرين تلقائياً عشان يدخل بمكانه. لو تبي تكسر السطر بمكان معيّن حط `\n`.

## جدول القياسات

للكادر الطولي 9:16. كم ياخذ الشخص من الكادر حوالين مركز راسه (`x`,`y`):

| `size` | الراس (عرض × ارتفاع) | الوجه يغطي | عرض الجسم | الإيدين المضمومة | الخصر |
|---|---|---|---|---|---|
| `wide` | 9 × 6.5 | x±5 · y±3.5 | x±13 | y+13 | y+21 (والرجلين لين y+46) |
| `medium` | 17 × 12 | x±9 · y±6 | x±22 | y+24 | y+39 |
| `mclose` | 22 × 15.5 | x±11 · y±8 | x±29 | y+31 | y+51 |
| `close` | 33 × 23 | x±16.5 · y±11.5 | x±43 | y+45 | برا الكادر |

**الغترة والشماغ والحجاب والشعر الطويل يعرّضون الراس**: احسب الراس x±14 للـ`medium` (بدل ±9) وx±18 للـ`mclose`، والفحص يحسبها كذا.

ارتفاع الكتابة حوالين مركزها: `huge` y±6 · `big` y±3.5 · `mid` y±2 · `small` y±1.5 (لكل سطر).

- **كتابة فوق الراس**: مركزها لازم يكون فوق `y الشخص − نص الوجه − نص ارتفاع الكتابة − 1`. مثال: شخص `medium` عند `y: 36` ← وجهه يبدأ عند 30، فكتابة `mid` مركزها 27 أو أقل، و`huge` مركزها 23 أو أقل.
- **كتابتين تحت بعض**: الفرق بين مركزيهم = نص ارتفاع الأولى + نص ارتفاع الثانية + 1. مثال: `huge` عند 14 وتحتها `mid` عند 23.
- **غرض ماسكه جنب وجهه** (`side`): مركزه `x ± 25` (medium). فخل الشخص عند `x` 42 إلى 58 عشان الغرض ما يطلع برا.
- **غرض مدّه قدام** (`forward`): عرضه مرة ونص عرض الراس، وياخذ من `x` الشخص لين `x+27` (medium) أو `x+35` (mclose)، من تحت ذقنه لين خصره. فخل الشخص شوي للجهة الثانية (`x` 40 مع `forward-right`).
- **الإيد اللي تأشّر** (`point`) توصل لين عرضين راس تقريباً من الكتف، مو لين الهدف لو كان بعيد.
- **أحجام الكتابة** بعرض الكادر: `huge` تشيل كلمة لين 6 أحرف · `big` كلمتين · `mid` 3 إلى 4 كلمات · `small` جملة قصيرة.
- **أماكن آمنة**: العناوين `y` من 8 إلى 24 · ملاحظة تحت `y` من 88 إلى 93 · خل أطراف كل كتابة بين `x` 6 و94 (الفحص ينبّه لو لزقت بالطرف).
- **ما تعرف وين طاح كل شي؟** شغّل السكربت مع `--map` يطبع لك بالنسبة المئوية مكان كل راس وجسم وإيد وعنصر وخلفية وشكل مونتاج وكتابة. (الأسهم والمقود والحزام ما ينطبعون.)

## تكوينات جاهزة

**كلام للكاميرا وعنوان فوق** (أكثر لقطة تتكرر):
```json
{"person": {"x": 50, "y": 56, "size": "medium"},
 "overlay": [{"text": "العنوان", "x": 50, "y": 14, "size": "huge"}, {"text": "سطر تحته", "x": 50, "y": 26, "size": "mid"}]}
```

**قاعد ورا مكتب واللابتوب قدامه**:
```json
{"person": {"x": 50, "y": 33, "size": "medium", "left": "point-camera", "right": "hide"},
 "props": [{"type": "table", "y": 67}, {"type": "laptop", "x": 50, "y": 69, "w": 74, "logo": "apple"}]}
```

**الشخص على جنب وشاشة كبيرة بالجنب الثاني**:
```json
{"person": {"x": 76, "y": 34, "size": "medium", "pose": "sit", "turn": "left", "arms": "open"},
 "props": [{"type": "monitor", "x": 30, "y": 47, "w": 56, "h": 38, "tilt": 1, "content": "page"}]}
```

**يعرض المنتج قدام الكاميرا**:
```json
{"person": {"x": 40, "y": 36, "size": "mclose", "hold": {"at": "forward-right", "item": {"type": "bottle", "label": "NOVA"}}}}
```

**لقطة قريبة للمنتج بلا وجه**:
```json
{"props": [{"type": "table", "y": 76}, {"type": "box", "label": "ZEN", "x": 40, "y": 50, "w": 48, "hand": "bottom"}],
 "overlay": [{"type": "list", "x": 80, "y": 24, "items": ["ميزة 1", "ميزة 2"]}]}
```

**شاشة جوال أو تسجيل شاشة ياخذ الكادر** (بلا تصوير):
```json
{"overlay": [{"type": "panel", "x": 50, "y": 46, "w": 78, "h": 70, "content": "app", "label": "تسجيل شاشة التطبيق"}]}
```

**داخل السيارة**:
```json
{"person": {"x": 50, "y": 38, "size": "mclose", "arms": "hide"}, "props": [{"type": "car-interior"}]}
```

**واقف قدام المحل** (لقطة واسعة):
```json
{"person": {"x": 30, "y": 52, "size": "wide", "arms": "open"}, "props": [{"type": "storefront", "x": 50, "y": 46, "w": 92, "label": "اسم المحل"}]}
```

**العرض والدعوة**:

## الفحص

| الملاحظة | الحل |
|---|---|
| الكتابة راكبة على الوجه أو غطاء الراس | حرّكها فوق الراس أو على جنب، أو نزّل الشخص. لو مقصود «كلام ورا الراس» حط `behind: true`. |
| «عنصر» راكب على الوجه | الغرض اللي بإيده أو قدامه مغطي وجهه: صغّره (`w`) أو بدّل `at`. |
| الكتابة راكبة على «عنصر» | حرّك الكتابة أو العنصر. المنتج لازم يبين كامل. |
| الكتابتين راكبين على بعض | باعد `y` بينهم حسب ارتفاع كل كتابة (جدول القياسات). |
| الكتابة طالعة برا الكادر أو لازقة بطرفه | قرّب `x` للنص أو قصّر النص أو حط له `w` أصغر فينقسم سطرين. |
| الكتابة طويلة على مكانها | النص أطول من المساحة حتى بعد التصغير: قصّره أو حط له `w` أعرض. |
| إطار الزوم يقطع الكتابة | صغّر `w`/`h` الإطار أو حرّك الكتابة برّاه. |
| كلمات من السكربت مو موجودة | رجّع الكلمات لأجزاء `script`. |
| N ملاحظات بلقطة وحدة | خل ثنتين وانقل الباقي لـ`direction`. |
