# النشر عبر بلوتاتو

## الفكرة
الصور تُرفع من جهاز المستخدم مباشرة لبلوتاتو (تُشفَّر بالطلب نفسه) — **ما يحتاج موقعاً ولا استضافة ولا سيرفر**. أنت تصمّم، وبلوتاتو يوصّل لحساباته الرسمية.

## ⛔ القاعدة الأولى — لا تنشر بلا إذن
النشر فعل خارجي ما ينعكس. **قبل أي نشر حقيقي:**
1. اعرض على المستخدم: الكابشن كاملاً + المنصات + التوقيت + عدد الصور.
2. انتظر موافقة صريحة («انشر» / «زين» / «تمام»).
3. بعدها بس شغّل الأمر.

لو المستخدم قال «انشر» من أول رسالة، اعرض عليه الملخّص أول ثم نفّذ — عرض سطرين مو سؤال ثقيل.

---

## أول مرة فقط: الإعداد

افحص وجود `accounts.json` بمجلد المشروع. **إن وُجد** انتقل مباشرة للنشر. **إن لم يوجد**، سوّ الإعداد بهدوء وبلا مصطلحات:

قل للمستخدم:

> عشان أنشر لك، أحتاج ربطك ببلوتاتو مرة وحدة:
> ١. سجّل بـblotato.com واربط حساباتك (انستقرام لازم يكون Business أو Creator ومربوط بصفحة فيسبوك).
> ٢. من Settings ← API انسخ مفتاحك.
> ٣. عند كل حساب مربوط فيه رقم — انسخ أرقام المنصات اللي تبيها.
> عطني المفتاح والأرقام وأنا أجهّز الباقي.

بعد ما يعطيك إياها، اكتب `accounts.json`:

```json
{
  "api_key": "<مفتاحه>",
  "accounts": {
    "instagram": "<رقمه>",
    "threads": "<رقمه>",
    "tiktok": "<رقمه>",
    "twitter": "<رقمه>"
  },
  "pinterest_board_id": ""
}
```

ثم:
- تأكد أن `blotato_publish.py` موجود بالمجلد (انسخه من ملفات هذا السكل إن لزم).
- ذكّر المستخدم بسطر واحد: «⚠️ لا تشارك accounts.json — فيه مفتاحك».
- أضف `accounts.json` لـ`.gitignore` إن كان المجلد مستودع git.

## النشر

### 1. جهّز الصور
لو المحتوى لسّه HTML أو شرائح بالمحادثة، صدّرها PNG أول بمجلد فرعي بأسماء مرتّبة (`slide-1.png`, `slide-2.png`…). الترتيب أبجدي، فاستخدم ترقيماً يحافظ على الترتيب.

فيه فيديو؟ حطه بنفس المجلد — بيصير أول عنصر بالكاروسيل تلقائياً.

### 2. اعرض الملخّص واستأذن (القاعدة الأولى فوق)

### 3. نفّذ

```bash
python3 blotato_publish.py <مجلد-الصور> --caption "الكابشن" --platforms instagram,threads
```

الخيارات:

| الخيار | الاستخدام |
|---|---|
| `--platforms` | instagram · threads · tiktok · twitter · pinterest (مفصولة بفاصلة) |
| `--caption` | نص المنشور · أو `--caption-file caption.txt` للنص الطويل |
| `--hashtags` | `"#وسم1 #وسم2"` — تنضاف آخر النص |
| `--when now` | نشر فوري (الافتراضي) |
| `--when time --time "2026-08-25T15:00:00Z"` | جدولة — **UTC**، والكويت = UTC+3 |
| `--when slot` | أقرب موعد فاضي بتقويم بلوتاتو |
| `--title` | لبنترست ويوتيوب |
| `--dry-run` | يعرض شنو بيصير بلا نشر — **استخدمه بأول مرة مع أي مستخدم جديد** |

### 4. بلّغ النتيجة
الأداة تطبع كل منصة نجحت ورقم عمليتها. انقل النتيجة للمستخدم بسطرين، وإذا فشلت منصة قل ليش بالعربي.

## خصوصيات المنصات — راعها بالكتابة

| المنصة | السلوك | اكتب له |
|---|---|---|
| **انستقرام** | كاروسيل، حد ١٠ عناصر | لو الشرائح أكثر من ١٠ نبّه واقترح شيل الأضعف |
| **ثريدز** | **عنصر واحد بس** | الشريحة الأولى لازم تكون مفهومة لحالها |
| **تيك توك** | منشور صور | نص أقصر وأقرب للكلام |
| **X** | تغريدة + ٤ صور، النص يتقصّر | خلّ أول سطر يشتغل وحده |
| **بنترست** | دبوس على لوحة | يحتاج `pinterest_board_id` + انتظار ~أسبوعين بعد ربط الحساب |

**حسابان بنفس المنصة؟** أضف رقماً للاسم بـ`accounts.json`: `"instagram2": "..."` — الأداة تفهمه تلقائياً وتنشر عليه بنفس صيغة انستقرام.

## الأخطاء وحلولها

| الرسالة | المعنى | قل للمستخدم |
|---|---|---|
| `ما لقيت accounts.json` | الملف مو جنب الأداة | حطه بنفس المجلد |
| `هذي المنصات ما لها أرقام` | منصة مطلوبة بلا رقم | ضيف رقمها أو شيلها من الطلب |
| `بلوتاتو رفض (401)` | مفتاح غلط/منتهي | جدّده من Settings ← API |
| `بلوتاتو رفض (400)` | غالباً انستقرام شخصي | حوّله Business واربطه بصفحة فيسبوك |
| `ما لقيت صوراً` | المجلد فاضي أو امتداد غريب | لازم png/jpg |

**مهم:** لو منصة وحدة فشلت والباقي نجح، لا تعيد النشر كامل — أعد المنصة الفاشلة وحدها بعد إصلاح سببها، وإلا ينزل المنشور مرتين.
