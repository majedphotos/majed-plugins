# Carousel Creator - مصنع المحتوى

## الهدف

> 🎬 **ريلات وفيديو؟** مو شغل هالسكل — استخدم «بلقن تحرير الفيديو» (`majed-video`): ريل من فيديو كلام، موشن، بودكاست، كفر وثمبنيل.


## 📐 قياس الكاروسيل (قاعدة موحدة)
- **المفضل والافتراضي: 1080×1440 (نسبة 3:4)** — أكبر مساحة مسموحة بفيد انستقرام، يبرز أكثر من 4:5.
- اقرأ «القياس المفضل» من `.auto-memory/creator-profile.md` — إن لم يوجد، اسأل المستخدم مرة واحدة (اقترح 1080×1440 كالأفضل، والبديل 1080×1350) واحفظ اختياره بالبروفايل.
- طبّق القياس المختار على **كل شي**: كاروسيل الصور، كفر الفيديو المتحرك، إعلانات المنتجات، والتصدير.

بناء كاروسيل HTML احترافي جاهز للنشر على انستقرام، بهوية المستخدم البصرية الكاملة، مع امكانية تصدير كل سلايد كصورة PNG بدقة 1080×1440 (أو القياس المفضل بالبروفايل).


## الخطوات

### 1. اقرا هوية المستخدم وملفات البروجكت

**اولا:** اقرا `.auto-memory/creator-profile.md` - إن لم يوجد، شغل سكل onboarding اولا.

استخرج: الالوان (رئيسي، تمييز، خلفية)، الخط، الاسلوب، اللهجة، اسم الحساب.

**ثانيا — مهم:** افحص ملفات البروجكت الحالي بحثا عن اي من:
- **شعارات / لوقو** (PNG, SVG, JPG) — استخرج الالوان الفعلية منها وطبقها بدل الالوان المكتوبة نصا
- **كاروسيلات سابقة** (HTML files) — افحص الالوان والخطوط والتصميم المستخدم فيها
- **ملفات هوية بصرية** (brand guide, color palette) — اقرا الالوان والخطوط مباشرة
- **اي صور تصميم** — استلهم منها الاسلوب البصري

**اذا لقيت اي من هذه الملفات:** استخدمها كمرجع اساسي للهوية البصرية — الملفات الفعلية اصدق من النص المحفوظ.

**للمستخدم عند انشاء البروجكت:** قل له "حط في البروجكت اي ملف يتعلق بهويتك البصرية — شعارك، كاروسيلات سابقة، الوان ثيمك — المكينة تقراها وتطبق نفس الهوية تلقائيا." 

### 2. اسال عن نوع الكفر — قبل اي شي اخر

**لازم تسال هذا السوال قبل ما تبدا التصميم:**

"الكفر (السلايد الاول) تبيه:
- **صورة ثابتة** — عنوان كبير وتصميم احترافي (اسرع وجاهز)
- **فيديو متحرك** — حركة تحكي قصة الموضوع في اول ثانيتين (اشد انتباه وأقوى)"

**اذا اختار فيديو متحرك:**
- قل له "ممتاز! خليني ابني الكفر المتحرك اول"
- شغل سكل `animated-video-cover` لبناء الكفر
- بعد ما ينتهي الكفر، ارجع وكمل باقي السلايدات بنفس الثيم والالوان

**اذا اختار صورة ثابتة:**
- كمل بناء الكاروسيل كاملا كما هو موضح ادناه

**اذا ما رد على السوال وطلب الكاروسيل مباشرة:**
- اسال مرة واحدة بشكل مختصر: "تبي الكفر صورة ثابتة ولا فيديو متحرك؟" ثم انتظر


### 2.4 🆕 الغلاف من نص الخبر (v5) — مو قالب

**كل غلاف فكرته من الخبر نفسه:** استعارة أو شي أو واجهة من الخبر (زر إيقاف، قفل، سطر كود يصير أداة، رقم ضخم…). ممنوع قالب ثابت يتكرر — التكوين والفكرة تتغيّر كل خبر.

1. **القراءة من فوق لتحت:** العنوان (جملة الخبر الرئيسية) فوق — **سطرين بالكثير** وكلمة وحدة مميزة بلون الهوية حسب المعنى — وبعده سطر ثاني أصغر. لا تكملة الجملة فوق بدايتها.
2. **كل كلمة ورقم من نص الخبر نفسه** — اختصار مسموح، اختراع ممنوع. وطابق كل عبارة على الغلاف مع الخبر قبل التسليم.
3. **ولا كلمة على وجه أو جسم شخص.** النص والصورة ما يتداخلون.
4. **خطّين بس:** خط عربي واحد (حسب الهوية) + خط لاتيني صغير للكلمات الإنقليزية. التنويع بالحجم واللون والتكوين، مو بالخط.
5. هوامش 60 بكسل أقل شي، والحساب صغير بمكان فاضي.

**📏 أحجام تنقرا بشاشة الجوال** (الشبكة تصغّر الغلاف لحوالي 12٪ من حجمه، وأصغر خط مقروء بالآيفون 11 نقطة):

| العنصر | أقل حجم على 1080 عرض |
|---|---|
| العنوان العربي | **150 بكسل** (أحسن 170+) — لو الجملة طويلة صغّره لين يدخل بسطرين، بس لا تنزل تحت 110 |
| أي نص ثاني | **90 بكسل** |
| الشعار / الأيقونة | **160 بكسل** |
| الخطوط والحدود | 10 بكسل (الأرفع يختفي) |

**افحص بعينك:** صغّر الغلاف لعرض 130 بكسل وشوفه — لو ما قريت العنوان، ما ينقرا بالبروفايل.

### 3. حلل الخبر
من النص المرسل، حدد:
- **الزاوية الرئيسية:** ما الخطاف الذي يجذب الجمهور؟
- **الارقام والحقائق:** كل رقم مهم يستحق سلايد مرئيا
- **السوال التفاعلي:** ما السوال الذي يحرك الكومنتس؟
- **الخلاصة والـ CTA:** كيف نختم بشكل يحفز المتابعة؟
- **عدد السلايدات المناسب:** بناء على كثافة المحتوى (4-8 سلايدات)

### 4. ابن هيكل السلايدات
الترتيب المثالي:
1. **الكفر** - عنوان صادم او رقم يجذب الانتباه (بدون مقدمات)
2. **الارقام/الحقائق** - مرئية وواضحة
3. **السياق والتحليل** - لماذا هذا مهم؟ (بلهجة المستخدم)
4. **السوال التفاعلي** - يحرك التعليقات
5. **سلايد المشاركة** - "تذكرت احد وانت تقرا؟ ارسلها له"
6. **الخلاصة + CTA** - دعوة للمتابعة

اذا كان الموضوع معقدا اضف سلايدات تشرح الجزئيات.

### 5. ابن ملف HTML
احفظ `carousel-[موضوع].html` في فولدر المشروع بالمواصفات:

**التصميم:**
- كل سلايد 1080×1440 نسبة (3:4 — الأكبر بفيد انستقرام)، أو القياس المحفوظ ببروفايل المستخدم
- الخلفية بلون هوية المستخدم
- الخط: Cairo او Tajawal من Google Fonts حسب الهوية
- اسم الحساب في اسفل كل سلايد

**قواعد RTL الزامية — بدون استثناء:**
- `<html dir="rtl" lang="ar">` و `body { direction: rtl; text-align: right; }`
- كل النصوص محاذاة يمين حتى لو كانت انجليزية (اسم المنتج، كلود، Claude، Opus...)
- لا تستخدم `text-align: left` او `direction: ltr` في اي عنصر محتوى
- الاستثناء الوحيد: الـ handle والارقام اللاتينية ترسم بـ `ctx.direction='ltr'` على الكانفاس فقط

**التفاعل:**
- ازرار "السابق / التالي" للتنقل
- نقاط الترقيم (dots) تتحرك مع السلايدات
- زر "حفظ هذا السلايد PNG" لكل سلايد منفرد
- زر "تصدير كل السلايدات PNG" يحمل كلها بالترتيب
- استخدم مكتبة html2canvas من cdnjs للتصدير بدقة scale:2.5


## 🆕 قواعد اتعلمناها بالتشغيل الفعلي (أغسطس ٢٠٢٦)

### الرمز يُختار من كلام البطاقة، لا من اسم الأيقونة
لما تحط بطاقات/نقاط لها أيقونات، **اقرأ نص البطاقة واختر الرمز منه**. لا تعتمد على اسم أيقونة
تكتبه أنت — لو ما لقى المحرّك الاسم يطلع أول حرف من الكلمة كشارة (ق أ خ) ويخرب الشريحة.

جدول مختصر للربط: قاضي/محكمة→مطرقة · قانون/عدل→ميزان · جامعة/أستاذ/تعليم→قبعة تخرج ·
كتاب/بحث→كتاب · خبير/تحليل/سياسات→عدسة · عالمي/دولي→كرة أرضية · فريق/شراكة→أشخاص ·
حكومة/مؤسسة→مبنى · جائزة/فوز→كأس · أمان/حماية→درع · سرعة→برق · سعر/اشتراك→فلوس ·
وقت/مدة→ساعة · نمو/أرقام→رسم بياني · إطلاق→صاروخ · تحذير/خطر→علامة تحذير.
ورتّب القواعد بحيث الأدق أولاً («توفير الوقت» ساعة، مو فلوس).

### حروف مكسورة عند التصدير
لو صدّرت الشرائح بمتصفح خفي (headless)، **انتظر تحميل الخطوط قبل الرسم**:
`await document.fonts.ready` مرتين قبل أي `drawImage`/`toDataURL`. بدونها تطلع مربعات
ومعيّنات مكان بعض الحروف («تو؟؟يل» بدل «توصيل») — والنص يبان سليماً بالكود.

### حدود ونصوص
- **10 شرائح** حد النشر الآلي لانستقرام (يدوياً يقبل حتى 20).
- **ممنوع كلمة إنقليزية بحروف عربية** («فلاج شيب») — إما إنقليزي أصلي أو ترجمة.
- **المصطلحات والأرقام التقنية تبقى إنقليزية**: 4K/120fps · f/2.0 · ISO 4000 · 20m · 50GB.
- **ممنوع رقم مو موجود بالمصدر** — لو ما لقيته بالنص الأصلي لا تكتبه.
- **ممنوع ميزتان بنفس الموضوع** أو نفس الصورة بشريحتين.

## قواعد الجودة - تفادي الاخطاء السبعة

طبقها تلقائيا في كل بناء بدون انتظار تعليمات:

### 1. الخط الصغير
الهوك (العنوان البطل) لازم يكون كبير وصادم. ولا نص في اي سلايد يقل عن **40pt** (بمقاس 1080)، بما فيه الفوتر ورقم السلايد. اجعل `fitFont` حدها الادنى 40 ولا تنزل تحته.

### 2. القياس الغلط
استخدم **3:4 (1080×1440)** وهو الأفضل والافتراضي — أكبر مساحة بالفيد. البديل لو طلبه المستخدم: 4:5 (1080×1350). لا تستخدم 1:1 المربع — يضيع نصف المساحة على الموبايل.

### 3. التصميم الجنريك بلا هوية
لا تطلع تصميم يبين "قالب جاهز". لازم: خلفية مدروسة، نظام الوان ثابت، ولمسة هوية (لوقو/توقيع/handle) في **كل** سلايد.

### 4. الازدحام
**فكرة واحدة فقط** في كل سلايد، مع مساحات فاضية (whitespace) تريح عين القارئ. لا تحشر كل المحتوى في سلايد واحد.

### 5. الصور الثابتة بدون حركة
اذا اختار المستخدم كفر ثابت، اجعل التصميم بصريا قويا جدا. اذا اختار فيديو، شغل سكل animated-video-cover.

### 6. البنية العشوائية
رتب: **هوك يصدم -> محتوى موزع بوضوح (نقطة لكل سلايد) -> سلايد مشاركة -> دعوة واضحة للاجراء**. لا توزع النقاط عشوائيا.

### 7. تكرار نفس الـ CTA
نوع الدعوة بين السلايدات: مرة "احفظها"، مرة "شاركها"، مرة "علق". التنويع يحرك اشارات تفاعل مختلفة (حفظ + مشاركة + تعليق) = وصول اقوى.

**تطابق العدد مع العنوان:** اذا قال العنوان "7 اخطاء/طرق/اسرار"، لازم المحتوى يحتوي 7 بالضبط مرقمة 1->7. لا تترك تناقض.

## دروس تصميمية - نطبقها في كل كاروسيل

### التسلسل البصري (Visual Hierarchy)
العين تروح للاكبر/الاعلى تباين اولا. رتب كل سلايد بثلاث طبقات:
- **رئيسي:** الكلمة/الرقم البطل - الاضخم وبلون الاكسنت، قرب المنتصف-الاعلى
- **ثانوي:** السطر المساند (السياق/الاجراء) تحت البطل مباشرة
- **ثالثي:** اللوقو + الـ handle - اصغر وأخف، موجودين بس ما ينافسون على الاضواء

**Squint Test:** ضيق عينك لين يصير التصميم ضبابي - اللي يبقى واضح لازم يكون العنوان البطل.

### CTA مشوق (فضول)
اجعل الدعوة تثير الفضول وتوعد بقيمة: "اسحب وتعرف عليها" / "اسحب تشوف الباقي" بدل "اسحب" الجافة.

### سلايد المشاركة (وصول مجاني)
اضف قبل سلايد الـ CTA الاخير سلايد يحفز المشاركة: "تذكرت احد وانت تقرا؟ ارسلها له". المشاركة لشخص معين ترفع الوصول اكثر من اي شي.

### ايقونات فيكتور بدل الايموجي
ارسم الايقونات بـ paths (strokes/fills) بلون الثيم بدل ايموجي النظام - الايموجي bitmap يتكسر مع الزوم ويبين اقل احترافية.

### النصوص اللاتينية باتجاه ltr
اي نص لاتيني (الـ handle، الابعاد، المصطلحات الانجليزية) ارسمه بـ ctx.direction='ltr' ثم رجعها 'rtl' - وإلا الـ RTL يقلب ترتيبه.

### منطقة الفوتر الامنة
ضع الفوتر (الـ handle + التاريخ) عند **y ≈ 1330-1390** من أصل 1440، وتأكد أنه ما ينقص على شاشات الموبايل.

### الدقة قبل التصميم
ابحث في النت وتاكد من اي ارقام/اخبار/مصطلحات قبل ما تكتبها في السلايدات - لا تعتمد على الذاكرة في الحقائق المتغيرة.

### الثيم حسب الموضوع
الكفر = خلفية الهوية الاساسية + لون اكسنت يخدم الموضوع. السلايدات الداخلية ممكن تاخذ ثيم الموضوع الكامل.

## قواعد البناء التقني — إلزامية لمنع الأخطاء

### ١. القياس — 1080×1440 (3:4)
```javascript
var CW = 1080, CH = 1440;  // كل القيم مربوطة بهذين المتغيرين فقط
```
```css
.stage{ aspect-ratio:1080/1440; }
.slides-inner{ width:1080px; height:1440px; }
.slide{ width:1080px; height:1440px; }
.slide canvas{ width:1080px; height:1440px; }
```

### ٢. القاعدة الذهبية — منع السلايدات الفاضية
مع `transform-origin:top left` استخدم `left:0` دائماً — أبداً `right:0`:
```css
/* صح */
.slides-inner{ position:absolute; top:0; left:0; transform-origin:top left; }
.slide{ position:absolute; top:0; left:0; }
```
`dir="rtl"` على الصفحة لا يغيّر هذه القاعدة.

### ٣. العدّاد — أرقام إنجليزية بصيغة الإجمالي/الحالي
```javascript
// داخل الكانفاس
function header(ctx, num, tag, total){
  var label = total + '/' + num;   // مثال: 7/2
  ctx.direction = 'ltr';
  ctx.fillText(label, x, y);
  ctx.direction = 'rtl';
}
// في HTML
counter.textContent = slides.length + '/' + (cur + 1);
```
```css
.counter{ direction:ltr; }
```

### ٤. الـ handle والنصوص اللاتينية
```javascript
ctx.direction = 'ltr';
ctx.fillText('@handle', 70, CH - 56);
ctx.direction = 'rtl';
```

### ٥. تحميل الخط — غلّفه بـ try/catch
```javascript
try{
  await document.fonts.load('900 90px Cairo');
  await document.fonts.load('700 46px Cairo');
  await document.fonts.load('400 46px Cairo');
  await document.fonts.ready;
}catch(e){}
```

### ٦. تشيك ليست قبل التسليم
- [ ] القياس 1080×1440 وكل القيم مربوطة بـ CW/CH
- [ ] الحاوية والسلايد على left:0 (مو right:0)
- [ ] العدّاد إنجليزي: الإجمالي/الحالي (7/1 … 7/7) مع direction:ltr
- [ ] الـ handle يُرسم بـ direction:ltr
- [ ] document.fonts.load داخل try/catch
- [ ] الفوتر مو مقطوع (y = CH - 56)
